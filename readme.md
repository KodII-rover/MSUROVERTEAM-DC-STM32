# Название проекта

Это полный проект **STM32CubeIDE** который использует созданную по программе **"КодИИ"** Программную библиотеку управления движения ровером на низком уровне(преобразование и исполнение высокоуровневых команд библиотеки навигации в управление приводами ровера) и обратной связи от датчиков ровера к системе навигации и компьютерного зрения, с целью оптимизации маршрута в процессе движения ровера. **Конкретно используется STM32 C модуль eureka_dc_lib.h. (Core/Inc/eureka_dc_lib.h, Core/Src/eureka_dc_lib.с)**
