# ОТКРЫТЫЕ БИБЛИОТЕКИ ДЛЯ АВТОНОМНОЙ НАВИГАЦИИ ШЕСТИКОЛЕСНОГО ПРОТОТИПА МАРСОХОДА (РОВЕРА) ПО УМЕРЕННО ПЕРЕСЕЧЁННОЙ НЕЗНАКОМОЙ МЕСТНОСТИ С ВИЗУАЛЬНЫМ РАСПОЗНАВАНИЕМ ЦЕЛИ НАВИГАЦИИ

## Открытая библиотека управления движения ровером на низком уровне (MSUROVERTEAM-DC)
## MSUROVERTEAM-DC-STM32

Это полный проект для среды **STM32CubeIDE**. В основе лежит программная библиотека, созданная в рамках программы **"КодИИ"**.

Проект обеспечивает:
*   Низкоуровневое управление движением ровера (преобразование высокоуровневых команд навигации в сигналы приводов).
*   Сбор и передачу обратной связи от датчиков в систему навигации и компьютерного зрения для оптимизации маршрута в реальном времени.

**Ключевые файлы модуля:** 
*   `Core/Inc/eureka_dc_lib.h`
*   `Core/Src/eureka_dc_lib.c`

**Аппаратное обеспечение:** STM32F4xxx.
**Уровень абстракции:** HAL для STM32 версии F4.

## ВАЖНЫЕ ЗАМЕЧАНИЯ

Для работы библиотеки управления движения ровером на низком уровне требуется корректная настройка и подключение аппаратно-программного интерфейса и корректная работа радиоэлектроники ровера.\
**Выбор конкретного аппаратного интерфейса для программной библиотеки остается на усмотрение пользователя. При изменении серии микроконтроллера работа библиотеки не может гарантироваться из-за серьезных отличий в функциях HAL и архитектурах чипов в разных поколениях STM32.**
